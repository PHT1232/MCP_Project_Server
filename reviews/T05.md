## Response shape for T07
Directory/top-tier: `{project, project_name, scope, scope_kind:"directory", depth,
generated_from:{indexed,last_full_at,last_incremental_at,last_commit,symbol_modes},
nodes[{id:"dir:|file:|ext:…", kind, path, label, language, loc, size_bytes,
file_count, symbol_count, fan_in, fan_out, has_children, outside_scope,
overlay:{focus,blockers,bugs,requirements,hot}}], edges[{source,target,kind,weight}],
stats:{total_files,total_resolved_edges,node_count,edge_count,truncated},
overlay_legend}`.
File scope: adds `dependencies[]` / `dependents[]`, `nodes` are `kind:"symbol"`
with `symbol_kind`/`start_line`/`end_line`/`signature`.
Full contract in `tasks/T05-codemap-api.md` handoff.

## Accepted deviations (from handoff)

1. **On-demand SQL aggregation, no persisted graph table, no migration.**
   **Confirmed OK.** The default call reads every non-skipped `files` row for the
   project (small rows, one indexed query) and folds in Python; a subtree call
   reads only its `path LIKE` prefix. `_load_edges` loads all `symbol_edges` per
   call. Fine at NFR1 scale; the handoff documents the move to SQL
   `GROUP BY split_part(path,'/',…)` without a contract change. **T09:** measure
   on a large repo; push the edge filter into SQL if it bites.
2. **LOC = `MAX(end_line)` of a file's chunks** (chunk ranges overlap, so
   `Σ(end-start)` over-counts); `size_bytes` also returned so T07 picks the
   weight metric. Accept.
3. HTTP route tested via service + MCP-tool tests + a route-registration
   assertion (not a 2nd `TestClient(build_http_app())` — one-shot session
   manager). Accept.
4. `get_code_map(project: str | None)` — matches every other `pcs.mcp` tool. Accept.

## Nits
- **N1** — `_load_overlay` runs 4 `get_section` queries per `get_code_map` call.
  Fine; could be one `UNION` query later.
- **N2** — a project with no code index → empty `nodes`/`edges` +
  `generated_from.indexed:false`. Graceful; T07 should show an "index this
  project" empty state.
