## Accepted deviations (from handoff)

1. **SCIP indexers not run end-to-end** — no `scip-*` / `rust-analyzer` binary
   installable offline here. The registry, `PCS_SCIP_INDEXERS` overrides, PATH
   probe, subprocess runner, and a hand-written SCIP protobuf decoder are all
   implemented; the decoder is unit-tested with hand-encoded bytes;
   `test_scip_real_binary_path_or_documented_skip` **skips loudly** (not xfail).
   The tags fallback — the path AC23 exercises — is fully tested. ⚠️ **Follow-up
   (T09 or a dedicated task):** verify against a real `scip-python` /
   `scip-typescript`; and **`run_scip_indexer` writes `index.scip` into the repo
   root, which is read-only in the T08 container** — the follow-up must direct
   output to a writable temp dir.
2. **Bundled `hashing` embedding backend** — zero-dep, offline, deterministic
   n-gram feature-hashing. Opt-in only (`PCS_EMBEDDING_BACKEND=hashing`); semantic
   search stays OFF by default, so D7's intent (no auto-semantic, no bundled
   heavyweight model) holds. It exists so AC8 / the semantic pipeline are testable
   without a network. **Accepted** — the alternative (no offline semantic test)
   is worse. Its lower quality is documented in the field description.
3. **`.env.example`** — applied by the reviewer (see above).
4. **`httpx>=0.27`** new dep — already transitive via `mcp`, now declared. Used
   for the embedding + FR9d HTTP backends. No `pgvector` python dep (raw-SQL
   vector casts), no `protobuf`.

## Nits
- **N1** — hand-rolled SCIP protobuf decoder; a truncated/garbage `index.scip`
  is caught (`except (OSError, ValueError, IndexError)` → fallback), so a crash
  can't escape, but `_read_varint` on a truncated buffer relies on that guard.
  Fine given input comes from a trusted local binary.
- **N2** — `embeddings` cache rows have no `project_id`/FK (pure content-hash
  cache). Orphans are harmless dedup rows and `DROP SCHEMA code_index` (AC15)
  clears them. OK.
