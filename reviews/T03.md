## Should-fix (follow-ups — assign to T04 / T09)

- **F1 / T04** — `index/schema.ensure_index_schema` **re-implements the 0003 DDL in raw SQL** and runs ~10 `… IF NOT EXISTS` statements on **every** `reindex` / `get_index_status` / `keyword_search` call. Two copies of the schema to keep in sync (T04 adds columns → must edit both), plus per-call DDL overhead. Move it to a one-time process guard or a startup hook; evaluate whether AC15 can be met by re-running Alembic instead of hand-maintained DDL.
- **F2 / T04 (NFR10 risk)** — `_index_one_file` spawns `git rev-parse HEAD:<path>` **per file**. A full index of a large repo = thousands of subprocesses. Batch with one `git ls-tree -r HEAD`, or drop the per-file blob entirely — `content_hash` already drives staleness.
- **F3 / T09** — `register_project` runs a **synchronous full index** (`index_if_root_exists`) inside the tool/HTTP call. For a large repo the register call blocks for minutes with no timeout. Background it or document the block.
- **F4 / T04** — `chunker._walk_boundaries` emits a chunk for **every** matching node, including nested methods and `export_statement` wrappers → a class and each of its methods overlap, and `export function foo` is chunked twice. Inflates the index and (for T04) embedding cost. Dedupe overlaps or index top-level boundaries + their direct children only.
- **F5 / T04** — `reindex` takes `resolve_project(for_update=True)`, the **same lock T01 uses for context writes**. A long index blocks `add_blocker` etc. for that project. Lock the `code_index.status` row instead.

## Nits
- **N1** — `alembic/env.py` adds `import pcs.index.models … # noqa: F401` (AGENTS.md discourages `noqa`). Side-effect import — use a cleaner pattern (`from … import models as _m; _ = _m`) or a targeted ruff `per-file-ignores`.
- **N2** — `watch._watch_loop`: `except (FileNotFoundError, Exception)` is redundant and reads as confusion; catch `Exception` alone with a comment, or narrow it.
- **N3** — `search._file_digest` re-reads each file **per hit**, not per unique path — dedupe when several hits share a file.
- **N4** — `chunker._walk_boundaries` is unbounded recursion over the syntax tree; a pathologically nested file could hit the recursion limit.
- **N5** — `to_tsvector('simple', …)` and trigram GIN on `content` for every chunk — fine now; revisit index bloat at scale (T09).
